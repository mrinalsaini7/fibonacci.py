# fibonacci.py
Fibonacci Calculator Project Description

This is a simple Python project that calculates the Fibonacci sequence. 

The program accepts a number as input and generates the Fibonacci sequence up to that specified number of terms. 

The Fibonacci sequence is a series of numbers where each number is the sum of the two preceding ones, starting with 0 and 1. 

Mathematical formula: F_n = F_{n-1} + F_{n-2} with base cases F_0 = 0 and F_1 = 1.

For example:

For n = 6:0, 1, 1, 2, 3, 5Project StructurePlaintext├── fibonacci.py

Enter the number of terms: 6
